Make or change a game with Claude

Games are made in Claude Code sessions on the hornbaek/glyphite repository. Each session builds, checks and opens a pull request; merging it to main deploys it here.

  1. Open a Claude Code session on the repository.
  2. Describe the game. Paste the prompt below and fill in your idea, or use a game's EDIT page to tune it and hand your changes to Claude.
  3. Review the pull request and merge it. The site updates after the deploy.
