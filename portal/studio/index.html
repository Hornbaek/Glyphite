        Help

        Every key, gesture and menu. ? opens this from anywhere.

        Compose music for the games in the style of the Super Nintendo: every instrument is a small sample with the console's grainy 4-bit compression, and the master has its echo. The sound comes from the engine itself, so a game plays a song exactly as you hear it here. Songs save to the site; a Claude session puts one into a game (File ▸ Put it into a game).

        Pair a phone

        Scan the code with the phone, or open the link and type the code. Same wifi; the phone signs in to the site once.

        The phone plays the selected track like a MIDI keyboard, so it records too; the sound comes out of this computer. If the phone sleeps it comes back to the same code by itself. Guest wifi that keeps devices apart blocks the link.

        Record a sample

        Sing, play or tap something into the microphone (up to 6 seconds). It becomes a sample you can play on the keyboard.

        Snapshots

        Named save points of this song, kept in this browser. Restoring one is an edit like any other: undo takes it back.
