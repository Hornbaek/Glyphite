Pixel lab

Two tools for getting art into a game. Snap cleans up "pixel art" from an image model: it finds the grid the drawing was meant to have and gives back one pixel per art pixel, in a few colours (Pixel Snapper by Sprite Fusion). Normals gives the clean sprite a normal map, so lamps and the sun in the game light it from the side they are on. Everything runs in this page; nothing is uploaded. When it looks right, copy the prompt for a Claude session, which runs the same tools on the repository's files.

1 The picture

or a drawing from a game's reference art:

Open a PNG or JPEG, or drop one on this page.

2 Snap to its grid

Pixel size is how many image pixels make one art pixel. The guess works on most AI sheets; when the result has far too few or too many pixels, measure one art pixel and type its size.

3 Normals

Bevel: how far in from the edge the shape rounds off (pixels). Detail: how much light paint stands out and dark paint sinks in (outlines follow the paint beside them). Strength: how steep it all is. Move the pointer over the lit picture to move the lamp.

[ PIXEL ART LIGHTER ↗ ] Hand-made normals: open the snapped PNG in Pixel Art Lighter (Moonfell RPG's tool: faceted surfaces, a brush to fix any area; best for buildings and hard shapes), export its normal map and load it here.

4 Into the game

A Claude session reproduces this from the repository's files with the same tools: copy the prompt (tell it which game and what the sprite is for), or the sprite's normals rows if you paste them in yourself.
